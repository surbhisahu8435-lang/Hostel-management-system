# Hostel Management System (C++)

## 📌 Description
This is a simple Hostel Management System project made using C++.  
It helps to manage student records in a hostel.

## 🚀 Features
- Add Student
- View All Students
- Search Student by Room Number
- Data stored using file handling

## 🛠️ Technology Used
- C++
- File Handling

## ▶️ How to Run
1. Open the file in C++ compiler
2. Run the program
3. Use menu options to perform operations
